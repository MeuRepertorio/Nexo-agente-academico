# NEXO — Agente Acadêmico

## Atualização: gráficos exatos e resolução para caderno

Esta versão preserva integralmente a base original: **8 matérias, 114 aulas, enunciados e gabaritos**.

O Laboratório Gráfico agora usa **funções e condições das atividades reais**, com gráficos diferentes para cada questão quando existem dados suficientes. São representados, quando aplicável, raízes, vértices, pontos calculados, valores físicos e escalas. Atividades que não permitem determinar um gráfico fiel apresentam a resposta escrita sem curva ilustrativa.

A área **Como organizar a resposta no caderno** separa os itens reais e o botão **Copiar resolução** inclui o gabarito e as etapas calculadas a partir das funções identificadas. Não é um tutor com geração de respostas online: os dados são locais e baseados na apostila.

### Como abrir

Abra `index.html` no navegador. É um arquivo único, sem necessidade de instalar dependências. O progresso continua no armazenamento local pela chave `nexo_completed_v1`.

### Publicação

GitHub Pages: **Settings → Pages → Deploy from a branch → main → /(root)**.

### Limitação do material

Algumas questões do caderno externo têm apenas respostas resumidas, sem o enunciado completo. Nessas questões o sistema não cria números ou gráficos não fornecidos. Para obter uma resolução específica adicional, é necessário ter o enunciado correspondente.

### Material de divulgação

Foram produzidas capturas reais do site em 3840×2160 (4K) para início, matéria, resolução e detalhes de Matemática/Física, entregues separadamente no chat como arquivos PNG.
